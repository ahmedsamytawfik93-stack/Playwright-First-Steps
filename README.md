📘 Playwright Practice Repository

This repository contains all the practice work I completed while learning Playwright. It includes test scripts, examples, and hands-on exercises that helped me understand the core concepts of Playwright and how to apply them in real test automation scenarios.

🚀 What's Included
- Fundamental Playwright commands and usage
- Locators & element interaction
- Assertions (auto-retrying & explicit)
- Working with test fixtures and test data
- Page Object Model (POM) structure
- Form handling and UI validations
- Navigation & page interaction tests
- Test structure using Playwright Test (describe/test blocks)
- Course practice assignments converted into automated scripts

🎯 Purpose of This Repository
The goal of this project is to track my learning progress, practice writing automated tests, and build confidence with Playwright. It serves as a personal reference for future automation projects and a foundation for more advanced Playwright features.

🛠️ Tech Stack
- Playwright – End-to-end testing framework
- TypeScript
- Node.js

📦 How to Run the Tests

Install dependencies:
npm install

Run tests in headed mode (see the browser):
npx playwright test --headed

Run tests in headless mode (default):
npx playwright test

Open the Playwright UI mode (interactive test runner):
npx playwright test --ui

View the HTML report after a run:
npx playwright show-report
